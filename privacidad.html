Política de privacidad

Última actualización: 10 de octubre de 2026.

Qué ocurre en esta web

La landing no envía formularios a un servidor. Al solicitar el piloto se abre la aplicación de correo del visitante con un borrador preparado. El envío solo se produce si el visitante decide enviarlo desde su correo.

Datos de contacto

Si envías la solicitud por correo se tratarán el nombre, restaurante, dato de contacto, formato documental y descripción del problema para responder, valorar el piloto y realizar las gestiones precontractuales solicitadas. La base jurídica es tu petición de medidas precontractuales y, para datos opcionales, tu consentimiento.

Documentos de compras

No envíes facturas, albaranes ni documentos con datos personales desde el formulario inicial. Antes de recibirlos se acordarán el canal, el alcance, el plazo de conservación y las medidas aplicables. Durante el piloto, el acceso se limitará a las personas necesarias para realizar el análisis.

Conservación y destinatarios

Los datos de contacto se conservarán mientras se responde a la solicitud y, si no continúa, durante el plazo mínimo necesario para atender responsabilidades. No se venden ni se utilizan para publicidad. El proveedor de correo puede tratar los mensajes conforme a sus propias condiciones.

Medición local

La web mantiene en cada navegador tres contadores agregados: visitas a la landing, clics en solicitar el piloto y usos de la demo. No incluyen datos de contacto, documentos ni identificadores y no se transmiten a Margen en esta versión.

Derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad escribiendo a [TU_CORREO_DE_CONTACTO]. También puedes reclamar ante la Agencia Española de Protección de Datos.

Antes de activar un piloto pagado se entregará una versión contractual con la identidad completa del responsable adulto y, cuando proceda, la información específica sobre el tratamiento de las facturas.
