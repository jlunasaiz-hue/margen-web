# Margen
Margen es una plataforma inteligente de control de costes para restaurantes. Analiza facturas, supervisa proveedores, detecta subidas de precios y posibles cobros duplicados, e identifica oportunidades de ahorro. Nuestro objetivo es ayudar a los negocios de hostelería a reducir gastos, mejorar su rentabilidad y tomar decisiones con datos.
